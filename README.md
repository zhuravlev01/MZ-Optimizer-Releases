# ⚡ MZ Optimizer

Современная утилита для тонкой настройки, оптимизации Windows и глубокой очистки системы.

### 🚀 Основные возможности
* **Оптимизация Windows** — твики производительности, отзывчивости и игрового режима.
* **Таймер 0.5 ms (Timer Resolution)** — минимальный инпут-лаг и стабильный фреймтайм.
* **Глубокая очистка** — удаление кэша шейдеров DirectX, NVIDIA, AMD и системного мусора.
* **Деинсталлятор UWP** — удаление встроенных приложений Windows и Edge.
* **Фоновый режим** — бесшумная работа в системном трее и автозагрузка.
